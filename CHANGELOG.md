# Changelog

## 0.1.1 — 2026-08-02

- Expanded the roadmap into global-sequence, epitope, physicochemical,
  structural, post-translational, and empirical-evidence layers.
- Added a documented scoring framework and a validation gate for any future
  composite model.
- Added MAFFT, BLOSUM62, RSA sensitivity analysis, patch RMSD, APBS/PDB2PQR,
  glycosylation, disulfide, annotated phylogeny, and interface deliverables.
- Explicitly prohibited presenting unvalidated computational features as a
  clinical cross-reactivity risk score.

## 0.1.0 — 2026-08-02

- Established the research question and interpretation boundary.
- Added the public-source provenance registry and inclusion protocol.
- Added source validation, automated tests, and GitHub Actions.
- Registered verified UniProt P01012 and RCSB PDB 1OVA starting records.
- Added an evidence-gated roadmap for sequence, epitope, and structure analysis.
